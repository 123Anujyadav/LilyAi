# Lily AI website

Vite + React + TypeScript rebuild of the Lily AI marketing site.

- Run: `npm install`, then `npm run dev`
- Build: `npm run build`
- Docs: `docs/website-redesign/` (start with `06-final-qa-and-handover.md`)

All product copy is in `src/content/site.ts`. Do not add product claims that are not in the approved source.
